# 多语言国际化 (i18n)

出海小游戏必须支持多语言，覆盖中/英/日/韩四种核心语言。

## 语言配置

```javascript
const LANGUAGES = {
  'zh-CN': { name: '中文', flag: '🇨🇳' },
  'en':    { name: 'English', flag: '🇺🇸' },
  'ja':    { name: '日本語', flag: '🇯🇵' },
  'ko':    { name: '한국어', flag: '🇰🇷' },
}

const DEFAULT_LANG = 'en'
```

## 使用方式

```javascript
let currentLang = detectLanguage()

function detectLanguage() {
  // 1. 优先读取用户手动选择
  const saved = localStorage.getItem('gameLang')
  if (saved && I18N[saved]) return saved

  // 2. 其次检测浏览器语言
  const browserLang = navigator.language || navigator.userLanguage
  // 精确匹配
  if (I18N[browserLang]) return browserLang
  // 前缀匹配 (zh-TW → zh-CN, ja-JP → ja)
  const prefix = browserLang.split('-')[0]
  const match = Object.keys(I18N).find(k => k.startsWith(prefix))
  if (match) return match

  // 3. 默认英文
  return DEFAULT_LANG
}

function t(key) {
  return I18N[currentLang]?.[key] || I18N[DEFAULT_LANG]?.[key] || key
}

// 切换语言
function setLanguage(lang) {
  if (I18N[lang]) {
    currentLang = lang
    localStorage.setItem('gameLang', lang)
    refreshAllTexts()
  }
}
```

## 带参数的文本

```javascript
// 支持变量插值
const I18N = {
  'zh-CN': { 'score.format': '得分: ${score}' },
  'en':    { 'score.format': 'Score: ${score}' },
  'ja':    { 'score.format': 'スコア: ${score}' },
  'ko':    { 'score.format': '점수: ${score}' },
}

function t(key, params = {}) {
  let text = I18N[currentLang]?.[key] || I18N[DEFAULT_LANG]?.[key] || key
  for (const [k, v] of Object.entries(params)) {
    text = text.replace(`\${${k}}`, v)
  }
  return text
}

// 使用
t('score.format', { score: 1000 }) // "得分: 1000"
```

## 数字格式化

不同语言有不同数字格式：

```javascript
function formatNumber(n, lang) {
  const locales = {
    'zh-CN': 'zh-CN',
    'en': 'en-US',
    'ja': 'ja-JP',
    'ko': 'ko-KR',
  }
  return n.toLocaleString(locales[lang] || 'en-US')
}

// 10000 → "10,000" (en) / "10,000" (ja) / "10,000" (ko)
```

## 语言切换 UI

```javascript
function createLanguageSwitcher() {
  const container = document.createElement('div')
  container.className = 'lang-switcher'
  container.style.cssText = `
    position: absolute; top: 10px; right: 10px; z-index: 100;
    display: flex; gap: 4px;
  `

  for (const [code, info] of Object.entries(LANGUAGES)) {
    const btn = document.createElement('button')
    btn.textContent = info.flag
    btn.title = info.name
    btn.style.cssText = `
      background: ${code === currentLang ? 'rgba(255,255,255,0.2)' : 'transparent'};
      border: 1px solid rgba(255,255,255,0.3);
      border-radius: 6px; padding: 4px 8px; cursor: pointer;
      font-size: 16px; color: #fff;
    `
    btn.onclick = () => setLanguage(code)
    container.appendChild(btn)
  }
  return container
}
```

## 字体注意事项

- 日韩文字需要系统支持对应字体
- 使用 `font-family: system-ui, -apple-system, sans-serif` 确保跨平台兼容
- 像素字体可能不支持 CJK 字符，需要为 CJK 文字单独指定 fallback 字体
- 数字和英文使用像素字体，中文使用系统字体的时候做好排版

```css
/* 推荐字体栈 */
.game-text {
  font-family: 'Press Start 2P', 'Noto Sans SC', 'Noto Sans JP', 'Noto Sans KR', system-ui, sans-serif;
}
```

## 排版适配

- 英文文本通常比中文长 30-50%，UI 按钮/标签需要预留宽度
- 日文和韩文长度介于中英文之间
- 使用 `min-width` 或弹性布局避免文字溢出
- 关键按钮使用图标 + 文字，减少语言依赖
